# FR Legends Resource Guide

A small independent resource website for players interested in FR Legends, covering cars, tuning, drifting, gameplay, and basic troubleshooting.

## About

This project is a simple static website built with HTML and CSS and hosted on Render.

The site is intended as a useful reference for players rather than an official game website.

## Pages

- **Home** — General FR Legends information and resource overview
- **Cars & Tuning** — Car selection, tuning approach, engine choices, and setup guidance
- **Gameplay Guides** — Drifting practice, controls, scoring, and gameplay fundamentals
- **Troubleshooting** — Common installation, compatibility, crash, and update-related issues
